**推估和模擬（不是量到的）**

- 各站上下車人次：年報的路線載客分到各站（推估）。刷卡資料沒有公開。
- 停站秒數換人次：用年報校準，每人約 10.7 秒（推估，只能比大小）。
- 駕駛：資料只看得到車，看不到駕駛。駕駛工作日、休息夠不夠、每週工時、要加多少人，都是推估或排班模擬。
- 等車時間：用量到的班距，套公式算（推估）。
- 路線重劃後的等車、用車、受影響人次：推估。
- 停靠位容量公式的參數、錢的單價：假設。
- **模擬刷卡資料（假資料）**：`network-card.html` 用電腦產生的刷卡上下車資料，跑同一套規則，只用來示範拿到真資料後會怎樣。不是真的資料。說明頁裡標「假資料」的例子也是。

## 限制

- 刷卡資料沒有公開：看不到車上有幾人、誰在轉乘。
- 只有臺北市公車和人口；新北客運不在資料裡，很多路線跨新北。
- 平日資料天數少（見上面的日期）。累積清單「3 天以上」的門檻在天數少時仍可能是巧合。
- 「上下車變多」和其他平日的平均比，所以越常擠的地方越不容易進清單，要和「看現況」一起看。
- 駕駛的數字都是車的數字推出來的。這些數字只代表班表上的風險，不代表業者違法。
- 停靠位置、折返路徑、換車步行距離都要到現場確認。
